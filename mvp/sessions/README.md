# Session records

Session-specific DoDs and wrap notes live here, outside the durable project
entry documents.

- Create active records as `active/YYYY-MM-DD-topic.md`.
- Move completed records to `archive/YYYY-MM-DD-topic.md`.
- Keep `CONTINUE.md` as the live handoff and link to the relevant archived
  session from its ledger.

Root-level documents are for current project law and state. They are not a
session archive.
